# 🎬 MovieFlicker

Discover your favorite movies and web series with **MovieFlicker**! Get in-depth details like ratings, cast, synopsis, and more—all in one place.

---

## 🚀 Features
✅ **Search** movies & web series effortlessly  
✅ **View Details** – ratings, cast, synopsis & more  
✅ **Responsive & modern UI**  

---

## 🛠️ Tech Stack
🔹 **Frontend:** React.js, Tailwind CSS  
🔹 **API:** OMDb API  

---

## 🔧 Setup & Installation

1️⃣ **Clone the repository:**
   ```sh
   git clone https://github.com/Saurav-KumarSingh/Analyse-movie.git
   cd client
   ```
2️⃣ **Install dependencies:**
   ```sh
   npm install
   ```
3️⃣ **Get an API Key** from [OMDb](https://www.omdbapi.com/)  
4️⃣ **Create a `.env` file:**
   ```sh
   VITE_API_KEY=your_api_key_here
   VITE_BASE_URL=your_base_url
   ```
5️⃣ **Run the app:**
   ```sh
   npm run dev
   ```
